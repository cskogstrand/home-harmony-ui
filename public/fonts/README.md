# Public Sans

Public Sans variable font, normal weight 400–700, Latin and Latin Extended subsets. Served locally for consistent English and Norwegian rendering.

Source: [Google Fonts](https://fonts.google.com/specimen/Public+Sans), version 21 assets. [Upstream project](https://github.com/uswds/public-sans). Distributed under the SIL Open Font License; see OFL-Public-Sans.txt.
